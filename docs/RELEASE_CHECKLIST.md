## 알려진 의존성 감사 항목

`npm audit --omit=dev`가 AppsInToss/Granite 빌드 도구의 Fastify 계열 전이 의존성을 보고한다. 자동 제안인 `@apps-in-toss/framework@1.14.1` 강제 설치는 현재 필수 SDK 2.x에서 1.x로 내려가는 비호환 변경이므로 적용하지 않는다. 앱은 외부 서버를 열거나 사용자 네트워크 입력을 처리하지 않으며 해당 패키지는 빌드·개발 서버 경로에 있다. 앱인토스 SDK 2.x의 호환 업데이트가 나오면 공식 릴리스 노트 기준으로 갱신한다.
